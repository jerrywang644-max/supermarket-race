Short adjectives

1-syllable adjectives: -er / -est
Tip: short adjectives → add -er / -est
Like Longman 4A: usually +er / +est (tall → taller → the tallest). Ending in -e: +r / +st (nice → nicer). Consonant + y: y→i (happy → happier). Short CVC: double the consonant (big → bigger, hot → hotter).
ADJECTIVECOMPARATIVESUPERLATIVE
tall / shorttaller / shorterthe tallest / shortest
old / youngolder / youngerthe oldest / youngest
heavy / happyheavier / happierthe heaviest / happiest
big / hot / thinbigger / hotter / thinnerthe biggest / hottest / thinnest
large / nicelarger / nicerthe largest / nicest

More and most

2- and 3-syllable adjectives
Long adjectives → more ___ / the most ___
Longman 4A Chapter 3: most two-syllable adjectives (not ending in -y) and all longer adjectives use more and the most — e.g. polite, helpful, delicious, popular, expensive, interesting.

Tricky words & common errors

y, ow, le — and watch out for “more cheaper”!
Watch spelling + do not double-mark!

double letterbig / hot / thinbigger / hotter / thinnerthe biggest / hottest / thinnest
irregulargood / badbetter / worsethe best / the worst
long adj.popular / expensivemore popular / expensivethe most popular / expensive
Common workbook mistakes — never mix rules: ❌ more bigger · ❌ more happier · ❌ the most tallest · ❌ more cheaper · ❌ the taller (for 3+ things)
